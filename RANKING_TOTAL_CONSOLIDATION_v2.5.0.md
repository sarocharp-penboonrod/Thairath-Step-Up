# Ranking Total & Cross-BU Department Consolidation — v2.5.0

## Decision
- Employee submission remains weekly average steps/day.
- BU ranking remains average-based.
- Department ranking changes to total-based:
  1. Average each employee's verified values inside the selected period.
  2. Sum those employee averages inside the consolidated department.
  3. Rank departments by `totalSteps` descending.
- Departments with the same canonical name are consolidated across BU.
- `DepartmentMapping` controls explicit canonical department / owner BU overrides.
- If no owner BU is configured, the system uses the BU with the largest active member count for that department.
